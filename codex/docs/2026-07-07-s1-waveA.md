## What changed in the working patch

- Added a `JUMP_LIFTOFF_MIN_UP_VEL_STEP` discriminator derived from
  `JUMP_IMMEDIATE_FORCE` with RocketSim `Car.cpp` provenance.
- Added unseeded liftoff-implied jump press candidate injection for Air segments
  with `Liftoff` boundary cause, seeded hints taking precedence.
- Added bounded liftoff press-release fitting for implied liftoff presses so the
  tracker can leave `Holding` when an early release fits better.
- Updated `car_state` to derive jump/double-jump timers from tracker ticks rather
  than treating every airborne frame as already jumped.
- Relaxed `CarTracker::first_jump_press` to allow first jump use from airborne
  idle tracker state for drive-off aerials.
- Reverted the noisy A2/A3 candidate broadening experiment before leaving this
  patch: broad cardinal dodge candidates and pre-null-fast-path kinematic
  gating increased quiet hallucinations too much.
