## Wave A11 truth-extraction audit (2026-07-08)

Status: completed as a diagnostic-only truth-side audit. **No production truth filter was applied** because the pre-registered P-A11 contrast was falsified.

### Scope and method

A11 probes the component stream that produced each WP7c known flip target. It reuses the existing WP7c coalesced known-flip target set (`3018` total), current unseeded HIT/MISS classification, and the Wave A9 FULL/CANCEL/NEITHER classifier.

For each known flip target the probe records:

- `counter_delta`: raw component counter advance at the selected emitting update (`dodge_raw` or `double_jump_raw` when exported; `NA` when the edge only has vector truth and no same-frame/raw counter value).
- `component_gap`: frames since the previous exported component update for the same player and same component attribute, using `ReplaySeries.component.events` plus raw counter-change frames.
- `arrival_mult`: count of reconstructed truth component events for that player within +/-2 frames of the selected truth frame.
- `rb_held_adjacent`: whether the truth frame is inside or adjacent to a held RB run, using the A10 freshness machinery.
- Actor reopen/new-actor channel marker: unavailable; `ReplaySeries` exports raw counters plus component events, but no relevancy re-entry marker.

The catch-up signature is exactly the pre-registered A11 rule: `counter_delta > 1 OR component_gap >= 5`.
