## Engine cross-check

Command:

```bash
cargo test -p rlinput --features sim portable_and_rocketsim_match_random_airborne_rollouts -- --nocapture
```

Acceptance: p99 position divergence `< 1 uu` and p99 angular-velocity divergence
`< 0.02 rad/s` at `t = 0.5 s`.

Observed overall p99: **3.411319 uu position**, **0.261379 rad/s angular
velocity**.

Primary blow-ups are flip torque classes, especially pure side flips and partial
cancels. Prime suspects, in order:

1. Portable rotation integration vs Bullet quaternion integration during high
   flip torque.
2. Flip cancel / side-flip torque ordering or basis application.
3. Dodge deadzone / event-control edge ordering.
4. Jump-hold integration order for the residual p99 position miss.

No tolerance was loosened and `portable.rs` was not patched.

## Convention round-trip

Command:

```bash
cargo test -p rlinput --features sim car_state_round_trip_preserves_axes_and_state -- --nocapture
```

Result: **PASS**. `CarPhysState -> RocketSim CarState -> CarPhysState` preserves
position, velocity, rotation basis, angular velocity, boost state, jump/flip
state, timers, and flip torque within `1e-5`.

The RocketSim injection also sets `last_controls.jump = state.is_jumping` and
`last_controls.boost = state.is_boosting`; without that, an injected active
jump-hold state creates a false second-press edge on the next tick.
