# S1 WP6a synthetic probe / cross-check report

Status: **WP6a2 COMPLETE under the reference-engine fallback**. The RocketSim
reference engine builds and the convention round-trip passes, but the historical
portable-vs-RocketSim cross-check still misses the non-negotiable tolerance.
Per the 2026-07-07 checkpoint ruling in the S1 estimator design, TheVoid is now
the scoring engine for gate-facing probe/benchmark work; the portable mismatch
remains an open fix track documented below.

## Engine cross-check

Command:

```bash
cargo test -p rlinput --features sim portable_and_rocketsim_match_random_airborne_rollouts -- --nocapture
```

Acceptance: p99 position divergence `< 1 uu` and p99 angular-velocity divergence
`< 0.02 rad/s` at `t = 0.5 s`.

Observed overall p99: **3.411319 uu position**, **0.261379 rad/s angular
velocity**.

Primary blow-ups are flip torque classes, especially pure side flips and partial
cancels. Prime suspects, in order:

1. Portable rotation integration vs Bullet quaternion integration during high
   flip torque.
2. Flip cancel / side-flip torque ordering or basis application.
3. Dodge deadzone / event-control edge ordering.
4. Jump-hold integration order for the residual p99 position miss.

No tolerance was loosened and `portable.rs` was not patched.

## Convention round-trip

Command:

```bash
cargo test -p rlinput --features sim car_state_round_trip_preserves_axes_and_state -- --nocapture
```

Result: **PASS**. `CarPhysState -> RocketSim CarState -> CarPhysState` preserves
position, velocity, rotation basis, angular velocity, boost state, jump/flip
state, timers, and flip torque within `1e-5`.

The RocketSim injection also sets `last_controls.jump = state.is_jumping` and
`last_controls.boost = state.is_boosting`; without that, an injected active
jump-hold state creates a false second-press edge on the next tick.

## Discriminability probe

Command:

```bash
cargo test -p rlinput --features sim discriminability_probe_dodges_and_double_jumps -- --ignored --nocapture
```

Harness: 256 seeded random legal airborne states per mechanic, 4-tick interval,
known event placement `k ∈ {0,1,2,3}`, generated and re-scored in
`RocketSimEngine` / TheVoid. Scoring used the provisional WP6 σ values
(`4 uu / 20 uu/s / 0.05 rad / 0.15 rad/s`) and tried all 4 placements for the
known event. Dodge direction was a random legal unit input per sample; double
jump used RocketSim's torque-free double-jump input.

| Mechanic | Clean top-1 placement | Noisy top-1 placement | Margin p10 | Margin p50 | Margin p90 | 1-tick pos Δ p10 | 1-tick pos Δ p50 | 1-tick pos Δ p90 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| Dodge | 100.0% | 99.6% | 28.340 | 154.831 | 203.505 | 4.171 uu | 4.665 uu | 6.412 uu |
| Double jump | 100.0% | 44.5% | 0.370 | 0.405 | 0.587 | 2.428 uu | 2.432 uu | 2.440 uu |

Result: dodge placement is strongly discriminable under the provisional noise
floor. The measured median one-tick dodge displacement is **4.665 uu**, matching
the design's ~4.2 uu claim. Double-jump placement is cleanly solvable without
noise, but the provisional σ makes noisy sub-tick placement near-degenerate
because the double-jump impulse creates only ~2.43 uu/tick of position
separation and no flip torque signal.

## Benchmark

Command:

```bash
cargo test -p rlinput --features sim benchmark_reference_and_portable_fit_cycles -- --ignored --nocapture
```

Local profile: `cargo test` debug build (`unoptimized + debuginfo`). The
reference benchmark uses one persistent `RocketSimEngine` arena and therefore
does the intended `set_car` reset per hypothesis. The event interval scores 48
dodge hypotheses; the null interval takes the null fast path and scores one
rollout.

| Engine | Null sims/sec | 48-hyp event sims/sec | 10k sims/player | 6-player replay projection | Affordable K @ 1s/player | Affordable K @ 10s/6p replay |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| RocketSimEngine / TheVoid | 32,462 | 30,912 | 0.324 s | 1.941 s | 154 | 257 |
| PortableEngine | 566,632 | 498,598 | 0.020 s | 0.120 s | 2,492 | 4,154 |

Result: reference-scoring all ~10k short sims/player is practical on this
machine even in the debug test profile. TheVoid is ~16× slower than the portable
pre-ranker on the 48-hypothesis event loop, but the measured 6-player replay
projection is still ~2 seconds for the design budget. A portable pre-rank →
reference top-K path remains available, but WP6a2 does **not** require it for
throughput; K is comfortably above the design's ≤48 event hypotheses under both
reported affordability budgets.
