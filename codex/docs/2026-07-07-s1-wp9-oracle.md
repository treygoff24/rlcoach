## Tautology guard

Test name: `calib::tests::withheld_channel_is_never_read_during_solve`.

The public oracle path constructs a `BlindSolverInput` that owns only a masked `ReplaySeries` and an unseeded strict-blind config. The original series is passed only to post-solve scoring. The guard test poisons replicated/component fields, asserts the masked solve input has neutral values for every withheld channel, runs the solver through `BlindSolverInput::solve()`, and asserts emitted replicated-channel sources are not `Replicated`.

## Ambiguities / limitations

- V1 currently uses the Python harness's portable one-frame positional approximation from solver output controls. It reports the frozen baseline artifact and smoke ratios, but the design's eventual “Rust side computes in the same pass” remains a stronger integration path for WP10/holdout tooling.
- Criterion-1 and criterion-3 numbers are dev-set reality and are far below gate bars; no threshold reinterpretation was made.
- The confidence table is raw reliability data only. No monotone calibration constants were committed in this WP because applying them would require touching solver/confidence emission files outside the owned scope.
